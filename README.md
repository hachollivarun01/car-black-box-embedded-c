# Car Black Box – Embedded C Project

An embedded C-based Car Black Box system designed for vehicle monitoring, event logging, and real-time data handling.

## Project Overview

The Car Black Box records and monitors important vehicle parameters and provides a user interface for viewing stored information. The project demonstrates embedded C programming, microcontroller peripherals, memory handling, and real-time event monitoring.

## Features

- Vehicle parameter monitoring
- Real-time clock integration
- Event/data logging
- Password-protected access
- LCD-based user interface
- Speed monitoring
- Gear monitoring
- External EEPROM data storage
- I2C communication
- Matrix keypad interaction
- Menu-driven operation

## Technologies Used

- Embedded C
- Microcontroller Programming
- I2C Communication
- LCD Interface
- External EEPROM
- RTC (Real-Time Clock)
- Matrix Keypad
- Embedded Systems

## Project Modules

- `main.c` – Main program and system control
- `menu.c` – Menu and user interface handling
- `speed.c` – Speed monitoring
- `gear.c` – Gear monitoring
- `realtime.c` – Real-time clock functionality
- `ds1307.c` – DS1307 RTC interface
- `i2c.c` – I2C communication
- `ext_eeprom.c` – External EEPROM operations
- `password.c` – Password management
- `chpassword.c` – Password change functionality
- `matrix.c` – Matrix keypad interface
- `clcd.c` – Character LCD interface
- `adc.c` – ADC operations
